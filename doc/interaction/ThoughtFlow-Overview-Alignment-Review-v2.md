# 总览页与统一交互 v2 对齐复核

日期：2026-11-05。对照[已确认设计 §3、§4、§12](ThoughtFlow-Workspace-Interaction-Design-v2.md)及[原型 homePage](ThoughtFlow-Workspace-Interaction-Prototype-v2.html)。范围为真实产品 `#/overview`、相关内容汇总 API 和导航链路，保留此前交互及专题命名改动。

## 差异与本轮实现

| 核对项 | 发现的差异 | 当前实现 |
| --- | --- | --- |
| 标题及说明 | 页面仍使用通用“总览”，说明缺少状态边界 | 使用“从讨论到完整成果”，说明保存、检查与正式批准分别记录；面包屑及主导航仍称总览 |
| 主次操作 | 操作存在，但与整体信息层级未完整衔接 | 标题区保留开始对话和浏览全部内容；日常归档仍直接在对话中完成 |
| 四项统计 | 没有原型图标层级，草稿项无法进入对应清单 | 加入图标、数字与标签分组；四项都可跳转，草稿携带 `kind=document_set&state=draft`，服务端实际过滤，清单可清除筛选 |
| 数量口径 | 不能从六条近期成果推导完整统计 | 沿用服务端完整保存清单的 counts，不使用前端分页重算 |
| 主体布局 | 最近成果铺满页面，会话和操作区另起一排 | 左列为最近成果及继续对话，右列为常用操作及需要关注；页面宽度、间距与白色面板按原型整理 |
| 成果卡片 | 多个按钮及元信息平铺，缺少底部操作分区 | 展示业务标题、摘要、正文／来源数量、职责标签、内容状态、固定版本及更新时间；打开和展开成员放在底部。独立文档采用对应单篇卡片 |
| 固定版本及失败更新 | 必须防止失败任务替换已保存成果 | 卡片及关注入口携带已保存的确切 selection；有新版本及任务失败另行标注，仍可打开已保存版本 |
| 继续对话 | 点击区域是文章容器；列表仅凭单篇 Thought 判断归档 | 改为原生按钮，支持键盘；服务端会话按最近更新时间排序，首页显示四条；从验证过的成果清单判断关联会话已有归档，不把受理或任务创建当作已保存 |
| 常用操作 | 缺少操作目的说明，并混入后台任务快捷入口 | 保留对话、Markdown 导入、来源成文三条路径，增加短说明；后台任务归关注项及健康管理 |
| 需要关注 | 整个区域缺失 | 增加未决设计选择和失败尝试；明确已有内容仍可读，提供固定内容入口、原会话入口及按需读取任务记录 |
| 关注范围 | 不能只看首页近期内容 | `overview=1` 在分页前汇总全部已保存内容及各套最新执行尝试；成功的新尝试替代旧失败提示；展示最多八条并返回真实总数 |
| 工作区健康 | 折叠区内仍是旧的多张状态大卡片 | 默认折叠，内部为紧凑状态摘要及实际设置链接，不占据首屏主内容 |
| 首次使用 | 不能展示原型示例数量和内容 | 真实空清单保留开始对话、导入 Markdown；关注为空如实说明 |
| 局部故障 | 会话失败没有就地重试，容易表现成无历史 | 会话失败独立显示错误及重试；内容失败清除不可确认的统计，并在内容和关注区给出重试；不改用旧笔记清单假装读取成功 |
| 竞争条件及更新 | 需防止迟到请求覆盖新内容 | 延续首页请求代次及离页保护，增加会话列表代次；内容／成果集事件触发合并刷新，不把内部事件日志直接塞进总览 |
| 窄屏及宽屏 | 原有样式使主、次区域关系与原型不同 | 总览采用 1240px 内容上限；桌面双列，较窄窗口主列和侧栏分行，移动端卡片及侧栏单列；不影响已调整的对话全宽布局 |
| 文案及键盘 | 新元素须双语并可聚焦 | 同步中英文和 key 注册；为注册表加入真实 ES module 导入与语法校验；会话及任务操作使用原生按钮，跳转采用链接 |

不复制原型中的示例账号、模拟成果、示例工作区状态或仅用于演示的操作。真实版本仍使用既有对象及审批、发布协议，本轮不迁移工作区或重写冻结成果。

## 8060 生效核对

独立请求 `http://127.0.0.1:8060/` 及其静态资源，确认正在提供的 HTML、CSS、应用脚本、成果卡片脚本及中英文资源均与本轮源码不同；与此同时，当前新二进制包含这些最新源码字节。运行中的旧进程不会因磁盘二进制被重新构建而更新嵌入页面。

因此应在正常停止旧服务后，用新二进制重新启动，再刷新 `http://127.0.0.1:8060/#/overview`。不可在同一工作区另起第二个写入进程。本轮未停止真实服务、发起真实模型请求或修改真实工作区。

```bash
./thoughtflow -config-dir ./config/
```
